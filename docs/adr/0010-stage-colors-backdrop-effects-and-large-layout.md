# ADR 0010 — 面ごとの地形の色をテーマから作り、背景の 2 層と演出は Render の側で描き、100 × 26 以上では窓を広げる

- 状態: 受理
- 日付: 2026-10-27
- Issue: #11
- 影響する規則: ARC-004 / ARC-007 / ARC-011 / FR-02h / FR-07 / FR-12 / FR-16
- 置き換える範囲: ADR 0007 の「面ごとの地形の色は Phase 3-5」と、ADR 0009 の 80 × 24 だけの配置

## 文脈

FR-12 は、12 テーマを兄弟から引き継ぎ、面ごとの地形の色を面の色合い（結晶の洞窟は青と水色・Q5）をテーマに合わせて決めること。
FR-02h は派手な演出（多層の背景のスクロール・爆発・得点の表示・ボス戦の前の警告の帯・面の始まりと終わりの大きな文字・溜め撃ちの光り・ボスの閃光）。
Phase 3-2 では、地形はテーマの岩と据え付けの 2 色だけで、面の違いが色に出なかった（ADR 0007）。

## 決定

### 面ごとの色（`StagePalette`）

- 面の色合い（岩・結晶・据え付け）: 草原は緑と木の色、結晶の洞窟は深い青と水色、空は雲の白っぽい青と淡い金、要塞は鋼の灰と赤い梁
- テーマの岩（据え付け）の色に面の色合いを 55%（据え付けは 50%・結晶は 65%）混ぜ、**地に対して 3:1 に届かなければ、届くまで文字の色へ 10% ずつ寄せる**
- コントラスト比の判定は製品のコードで行うので、浮動小数点の `pow` を使わない（libm に頼らない・ADR 0001 の X-i）。sRGB の 256 段を線形に直した値を
  1 万倍の整数の表（`Luminance.linear`）で持ち、整数だけで「3:1 以上か」を判定する。表はテストが浮動小数点の WCAG の計算と突き合わせる（1% 以内）
- 結晶は 20 刻みごとにずれてところどころ光る

### 背景（`Backdrop`）

- 窓を地の色で消し、遠くの層（`.`・カメラの 1/4 の速さ）と近くの層（面ごとの字: 草原 `'`・洞窟 `*`・空 `~`・要塞 `|`・1/2 の速さ）の点を置く
- 点の置き場所は層の中の位置の番号をかき混ぜて決め、およそ 40 か所に 1 か所（乱数を読まない・ARC-007）。最初の素直な混ぜ方では点がななめの縞に並んだので、ビットをかき混ぜる形にした
- 点は ASCII の 1 文字で、地の上にだけ置く。そのあと地形と体を塗るので、塗ったセルに文字は残らない（FR-07・テストで見る）

### 演出（Render の `Effects`・Swarm から移植）

- 出来事から作る見た目の状態（浮かぶ得点・WARNING の帯の残りの刻み・演出の時計）は Render の `Effects`。合成ルートが刻みごとに出来事を渡す。Core には入れない（ADR 0004）
- 浮かぶ得点: 倒した場所に `+100` などを 30 刻み出し、10 刻みに 1 行上がる。塗ったセルの上には書かない
- ボスの前の警告: ボスが現れたら 75 刻み、窓の真ん中に `WARNING` の大きな文字を危険の色で点滅させる
- ボスの閃光: ボスが光る攻撃の間（Core の `BossAttack.flash`）、窓の地が火花の色を帯びて 2 刻みごとに明滅する（背景の点は出さない）
- 溜め撃ち: 溜めている間は自機が火花の色へ寄り、溜まったら火花の色と交互に光る
- ゲームの状態だけから描けるもの（倒れた敵の点滅・消える足場の点滅・面の始まりと終わりの帯）は状態から描く

### 広い配置（100 × 26 以上）

- 窓を **49 セル × 18 段**（98 桁）にし、COMMS を直近の 2 行（古い方は控えめな色）にする。HUD とキーの帯は同じ
- 配置は `ScreenLayout.compact` と `.large` の 2 つの値で、窓の大きさ・カメラ・筆（`FieldBrush`）・文字の札はどれも配置を受け取る

## 強制

- **active**（Render のテスト）: 12 テーマ × 4 面の岩・結晶・据え付けが地に対して 3:1 以上・結晶の洞窟が青い・整数の明るさの表が WCAG の計算と合う・
  背景の点は ASCII で地の上だけ・浮かぶ得点が消える・WARNING の帯・広い配置で窓の幅と COMMS 2 行・2 つの配置でカメラが面の外を映さない・
  既存の「面の窓の色のセルに文字が無い」と「画面の英数字は 4.5:1 以上」
- **planned**: 実機の見え方とちらつき（Phase 3-3 の画面写真）

## 結果

- 4 つの面が色でも見分けられ、結晶の洞窟は青と水色になった。どのテーマでも地形が地に沈まない
- 背景が流れ、倒すと得点が浮かび、ボスの前に警告が出て、ボスが光ると窓が明滅する
- 失うもの: 面の色合いはテーマの岩の色と混ぜるので、テーマによっては面の色合いが薄まる（MONO では灰の濃淡だけになる）

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 12 テーマ × 4 面 × 3 色の 144 色を手で決める | 数が多く、テーマを足すたびに面の色も決め直すことになる。色合いを混ぜてコントラストで直す 1 つの規則にした |
| コントラストの判定を浮動小数点の `pow` で書く | 標準モジュールを import しない実行ファイルで libm にリンクできない（X-i）。整数の表で足りる |
| 背景の点を乱数で置く | Render は乱数を読まない（ARC-007）。番号から決めれば足りる |
| 背景を色を塗ったブロックで描く | 地形や体と見分けにくい。飾りは文字の点にして、FR-07 のブロックと分けた |
| 演出の状態を Core の `Game` に持たせる | 当たり判定に関係しない値がゲームの状態に入る（ADR 0004） |
