# ADR 0005 — 座標は 1 セル 16 単位の整数で持ち、面は文字の地図で書き、ゲームは固定の順番の 1 刻み関数だけで進める

- 状態: 受理
- 日付: 2026-10-27
- Issue: #3
- 影響する規則: ARC-001 / ARC-004 / ARC-005 / ARC-007 / SWF-001 / SWF-002 / SWF-003 / SWF-014

## 文脈

NeNe Bolt は Swarm と同じくリアルタイムで、Core は時計を知らない（ADR 0004）。Swarm の ADR 0005 の制約（`Double.squareRoot()` がリンクできない X-i・X-j、
負の数の `/` と `>>` の丸めの違い X-k・X-l、`Int32` の桁あふれ X-m）はそのまま効く。Swarm と違うのは次の 3 点。

- 盤面が端末より広い横スクロールで、地形（床・壁・梯子・氷・棘・コンベア・消える足場）がある。自機は重力で落ち、地形に乗る
- 人が遊ぶ（FR-04a）。人のキーと AI の判断が同じ入力の型で Core に入る（ADR 0004）
- 4 面の地形は決まっていて毎回同じ（FR-05・FR-02b）。変わるのは敵の出方とボスの攻撃の順だけ

## 決定

### 座標と面

- 1 セルは **16 単位**（`Field.cellShift = 4`）。座標は `Int`。セルへの変換は `Field.cell(_:)` の 1 経路で、`>>` で負の無限大へ丸める
- 面は**文字の地図**（`StageCatalog`）で書く。1 ページ 90 桁で、ページを左から右へつなぐ。草原・空・要塞は 180 × 18 セル、結晶の洞窟は縦に登る区間のため 180 × 30 セル
- 地形の文字は 1 文字 1 種類（`#` 固い・`=` 氷・`H` 梯子・`^` 棘・`<` `>` コンベア・`0`〜`3` 消える足場の組）。出てくる物（自機・敵・拾うもの・動く足場・中間地点・ゴール・扉・ボス）も文字で置き、読み込むと取り除く
- 地図の読み込みは `StageMap.decode` の 1 経路で、壊れた地図（幅のそろわない行・知らない文字・自機が無い・ゴールもボスも無い）は閉じた enum の結果で拒む。面の外は、左右と上が壁、下が穴
- 地図は製品に埋め込んだ文字列で、ファイルから読まない（Core はファイルを知らない）

### 自機の動き（整数の放物線）

| 項目 | 値（単位・刻み） |
| --- | --- |
| 自機の箱 | 幅 12 × 高さ 28（1 セル弱 × 2 セル弱） |
| 走る | 3／刻み。氷の上では速さが 2 刻みに 1 ずつしか変わらない（走り出しも止まるのも遅い） |
| 跳ぶ | 上向き 11 で跳び、毎刻み重力 1。跳ぶボタンを離すと上向きの速さを 3 に切る（押している長さで高さが変わる・FR-02） |
| 落ちる | 最大 12／刻み |
| 梯子 | 上下 3／刻み。梯子のいちばん上は上からだけ乗れる床 |
| 踏む | 落ちながら敵の上面から 6 単位以内に足が入ったら踏んだことにし、上向き 7 で跳ね返る |
| 体力 | 10。被弾の後 45 刻みは無敵。尽きたら 1 機失う |
| 撃つ | 押した瞬間にふつうの弾（強さ 1＋パワーアップの段）。画面に 3 発まで |
| 溜め撃ち | 撃つボタンを 30 刻み押し続けて離すと大きな弾（倒した敵を貫通・強さ 4） |
| パワーアップ | 0〜2 段。弾の強さが上がり、被弾で 1 段戻る |

- **動く物はどれも、1 刻みの移動を 4 単位以下に刻み、刻むたびに地形との当たりを見る**（`Game.slide`）。4 単位はどのセル（16）・どの体（最小 8）より小さいので、最大 12 で落ちても床を突き抜けない。ぶつかったら 1 単位ずつ寄せて壁や床にぴったり付ける
- **刻みを始めたときに既に重なっている固い地形のセルは、その刻みの当たりから外す**。消える足場が自機の体の中に現れても、自機は閉じ込められずに抜け出せる（テストで見つけた・下）
- 横 → 縦の順に動かす。動く足場は自機より先に動いて乗っている自機を運び、コンベアは立っている自機の横の動きに 1／刻みを足す

### 消える足場

`VanishingClock` が面の刻みだけから決める。周期 120 刻み・見えている 54 刻み・組ごとに 30 刻みずらす。0 → 1 → 2 → 3 の組の順に現れて消え、毎回同じ（FR-02b）。
消えている間は空気と同じで、乗っている間に消えたら落ち始める。乱数を使わない。

### 1 刻み関数

- ゲームを進めるのは `Game.step(_:difficulty:using:)` の 1 経路だけ。状態＋押されているボタンの組（`Buttons`）＋乱数源 → 次の状態と出来事（`GameStep`）。終わったゲームは変わらない
- `Buttons` は左・右・上・下・跳ぶ・撃つのビットの組。**人のキーも AI の判断もこの型で入る**（ADR 0004）。跳ぶ・撃つの「押した瞬間」は前の刻みのボタン（`runner.held`）との差で Core が決める
- 遊んでいる刻みの順番は `Game+Advance.swift` の 1 か所で決める: 制限時間 → 動く足場 → 自機の操作と動き → 穴と棘 → 自機の弾 → 敵 → 敵の弾 → 体当たりと踏みつけ → 拾うもの → 中間地点・ゴール・ボスの部屋 → ボス。途中で 1 機失ったら、その刻みの残りは進めない
- `Game` の格納プロパティは `public internal(set) var`（Swarm と同じ）。難易度は毎刻み引数で受け取り `Tuning.make(difficulty:stage:)` で敵の強さに直す（FR-14）
- 場面（TITLE → PLAY → GAME OVER か ENDING → TITLE）は `Session.step` の 1 経路。ボスを倒したゲームだけが ENDING へ行く

### ゲームの中身（数）

| 項目 | 値 |
| --- | --- |
| 面 | 4 面（草原・結晶の洞窟・空中の足場・要塞）。各面の真ん中に中間地点。1〜3 面は旗のゴール、4 面は扉の奥のボスの部屋（入ると扉が閉じる） |
| 制限時間 | 1 面 5,400 刻み（30 刻み／秒で 3 分）。残り 900 刻みで急かす。尽きたら 1 機失う。ゴールで残りの秒 × 10 点 |
| 残機 | 始まりは画面の 1 機＋控え 2。コイン 100 枚で 1UP |
| 敵 | 歩く・跳ねる・飛ぶ・砲台（踏めない）・割れる結晶（倒すと欠片 2 つ）。自機から 20 セル以内に入ると動き出す |
| ボス | 幅 28 × 高さ 40。間を置いて、跳ぶ・扇に 3 発・壁まで突進・光って 5 発、を乱数で選ぶ。倒すと 5,000 点で ENDING |
| 得点 | 敵 50〜300・コイン 10・回復 50・パワーアップ 300・1UP 500 |
| 終わり方 | 残機が尽きる・4 面のボスを倒す・刻みの上限 36,000（20 分。安全のため。届いた割合は ADR 0006） |
| 強まり方 | `Tuning`。難易度が上か面が後なら、敵の速さ・跳ねる間隔・砲台の間隔・弾の速さ・触れたときの強さ・ボスの体力・ボスの間のどれも敵に有利か同じ |

## 強制

- **active**（テスト・ADR 0006）: 決定性・範囲（地形に埋まらない）・当たり判定（床を突き抜けない）・消える足場・数の保存・場面の遷移・必ず終わる・難易度の単調性
- **active**（規約検査）: CNF-012・CNF-011・CNF-016・CNF-013（Swarm の ADR 0005 と同じ）
- **planned**（レビュー事項）: 刻みの順番を 2 か所に書かないこと。面の地図が「人が渡れる」こと（穴の幅 3 セル以下・足場の間の隙間 3 セル以下）は、テストのランナーが通れた区間しか機械が見ていない

## 結果

- 刻みの速さを変えてもゲームの中身は変わらない（見える速さだけが変わる）
- 消える足場が自機の体の中に現れても閉じ込めないこと（既に重なっているセルを当たりから外す）と、梯子のいちばん上に立てて梯子の途中からは上へ登れることを、
  手で作った場面のテストで塞いだ（`PhysicsTests`）
- 面の地図は、書いている途中の計測で、4 セル以上の穴・届かない足場の隙間・ボスの出る位置が床に埋まっている所を見つけて直した（穴と隙間は 3 セル以下・
  隙間が広い所は動く足場を渡す）
- 失うもの: 当たり判定は箱だけで、坂は無い。坂は要件に無い

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| `Double` で座標と重力を持つ | libm にリンクできない（X-i・X-j）。丸めの違いで同じシードから別のゲームになる心配もある |
| 面を乱数で作る | 「覚えて渡る」消える足場（FR-02b）と、面の雰囲気の決定（Q5）に合わない。面は決まっていて、変わるのは敵の出方 |
| 面をファイル（テキストや JSON）で持つ | Core はファイルを知らない（ADR 0004）。合成ルートが読むと、読めないときに面が無い場合が生まれる。製品に埋め込めば壊れた地図はテストで見つかる |
| 1 刻みに 1 回だけ箱で地形と当てる | 最大の落ちる速さ 12 は床の厚さ 16 に近く、速さを上げると突き抜ける（REQUIREMENTS 第 3 節の罠）。移動を刻む |
| 消える足場が現れたら、重なった自機を上へ押し出す | 押し出す先が別の固い地形だと、さらに押し出す規則が要る。重なったセルを当たりから外す方が 1 経路で済む |
| 人の入力を「押した・離した」の出来事の列で Core に渡す | 押す・離すを受け取れない端末（FR-04b）では出来事が作れない。押されているボタンの組なら、どちらの方式でも合成ルートで作れる |
| 消える足場の間隔を乱数で揺らす | 覚えて渡るもの（FR-02b）にならない |
